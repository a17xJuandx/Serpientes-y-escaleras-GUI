# Sistema de Simulación y Estadísticas - Serpientes y Escaleras (GUI)

Aplicación gráfica desarrollada en Java utilizando **Java Swing (`JFrame`, `JButton`)** para simular de forma visual e interactiva el juego tradicional de Serpientes y Escaleras, integrando un panel de control en tiempo real y generación de estadísticas de la partida.

## Descripción

El proyecto implementa una interfaz gráfica donde el usuario puede interactuar directamente con el tablero y los componentes visuales de la aplicación.
* **Ejecución en Tiempo Real:** Permite accionar botones (`JButton`) para mover las fichas de manera dinámica sobre la interfaz gráfica.
* **Estadísticas de la Partida:** Muestra un panel con métricas detalladas y el estado de los jugadores conforme avanza la simulación del juego.
* **Interfaz Gráfica:** Diseñado mediante formularios y componentes visuales basados en Java Swing.

## Componentes Técnicos

* **Entorno Gráfico:** Java Swing (`JFrame`, `JButton`, paneles y contenedores personalizados).
* **Conceptos aplicados:** 
    * Programación Orientada a Objetos (POO)
    * Manejo de eventos de interfaz gráfica (`ActionListener`)
    * Estructuras de control y actualización de estados en tiempo real
    * Estructuración de lógica de juego vinculada a vistas visuales

## Instrucciones de Ejecución

1. Abrir el proyecto en un entorno de desarrollo compatible con Java que soporte Swing (como NetBeans).
2. Asegurarse de mantener la estructura de la carpeta `src` que contiene los paquetes con los archivos fuente y los formularios gráficos.
3. Compilar y ejecutar la clase principal o el `JFrame` de inicio desde el entorno.
